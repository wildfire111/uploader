# Event Results Tool

Tools for the 7PH community, live at [thoughtca.st](https://thoughtca.st).

- **Uploader**: volunteers enter tournament results and decklists, and an admin reviews them and publishes each deck to Moxfield. Login is by invitation.
- **Sideboard** ([thoughtca.st/sideboard](https://thoughtca.st/sideboard)): a sideboard planning guide.
- **Check** ([thoughtca.st/check](https://thoughtca.st/check)): a tool for judges to flag decklist errors. Upload a Melee decklist PDF and click through each list with its errors shaded.
